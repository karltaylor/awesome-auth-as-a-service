# Awesome Auth As A Service

A curated list of authentication and identity-as-a-service providers. These platforms handle user authentication, identity management, SSO, MFA, social login, and other security-related features so you don't have to build them yourself.

## Authentication Platforms

### [OAuth.io](https://oauth.io/)
OAuth.io provides a simple API for adding OAuth authentication to applications. It supports hundreds of identity providers and simplifies social login integrations.

### [Auth0](https://auth0.com/)
Auth0 is a widely adopted identity platform for developers. It provides authentication, authorisation, SSO, MFA, user management, and enterprise identity integrations.

### [AuthRocket](https://authrocket.com/)
AuthRocket is an authentication service focused on providing user management, login flows, and identity infrastructure without requiring developers to build their own auth systems.

### [AWS Cognito](https://aws.amazon.com/cognito/)
Amazon Cognito is AWS's managed identity service. It provides user pools, authentication, authorisation, social sign-in, and deep integration with AWS services.

### [Clerk](https://clerk.com/)
Clerk is a developer-first authentication platform with pre-built UI components and APIs for user management, authentication, organisations, and session handling.

### [Descope](https://www.descope.com/)
Descope is a passwordless authentication and identity platform focused on secure authentication flows, MFA, passkeys, and enterprise identity management.

### [Firebase Auth](https://firebase.google.com/products/auth/)
Firebase Authentication is Google's authentication service for web and mobile apps. It supports email/password login, social providers, phone authentication, and anonymous users.

### [PingIdentity](https://www.pingidentity.com/)
Ping Identity provides enterprise identity and access management solutions, including SSO, MFA, API security, and workforce/customer identity management.

### [LoginRadius](https://loginradius.com/)
LoginRadius provides customer identity and access management (CIAM) tools, including social login, user profiles, authentication workflows, and enterprise integrations.

### [Neon Auth](https://neon.com/docs/neon-auth/overview)
Neon Auth is an authentication service built around the Neon serverless Postgres ecosystem, providing integrated user authentication for applications using Neon databases.

### [Okta](https://www.okta.com/)
Okta is an enterprise identity platform offering workforce and customer identity management, SSO, MFA, lifecycle management, and developer APIs.

### [Userbase](https://userbase.com/)
Userbase provides simple user authentication and encrypted data storage for applications, allowing developers to add accounts and private user data without managing backend infrastructure.

### [WorkOS](https://workos.com/)
WorkOS provides enterprise-grade identity infrastructure APIs, including SSO, directory sync, audit logs, and user management features designed for SaaS applications.

## Related Categories

- **Developer-first authentication:** Clerk, Descope, Auth0, Firebase Auth
- **Enterprise identity:** Okta, PingIdentity, WorkOS
- **Cloud-provider solutions:** AWS Cognito, Firebase Auth, Neon Auth
- **Customer identity (CIAM):** LoginRadius, Auth0, Okta
